# コンセプト

## プロダクト定義

**タイトル:** 圏外
**英字表記:** NO SERVICE
**第1話:** 届いてる？

> 最先端の眼鏡に、2008年に死んだ少女のメールが届く。返信するほど、それが彼女の文章ではなくなっていく。

「圏外」は、Even Realities G2の粗い緑色表示を、欠点ではなく人格復元ログの表示規格として扱う短編SFミステリーである。プレイヤーは2008年の日付を持つ携帯メールを受信するが、相手のミナは2026年には死者であり、メールは17台の回収端末から作られた`M-17`の補完だったと判明する。

## 体験の核

最先端デバイスと古い携帯画面のミスマッチを、次の一文で説明できることを最優先する。

> この眼鏡は、死者のメールを受信したのではなく、死者らしい返信を作る実験へ接続してしまった。

G2の制約を隠さず、すべて物語へ変換する。

| G2の特徴 | 体験内での意味 |
| --- | --- |
| 緑色で粗い文字 | 過去の携帯表示を復元している |
| 音声出力がない | 着信音さえ失われた静かなメール |
| 上下・決定中心の入力 | ガラケーの方向キーと決定ボタン |
| 小さなモノクロ画像 | 破損・再圧縮された添付写真 |
| 文字中心の表示 | 短い件名と本文で進む携帯メール |
| G2の実時刻・電池 | 古いUIへ現在が漏れ込む証拠 |

## デザイン原則

1. **最初の30秒で異常を示す。** 最初のメールには2008年の日付と「そっちは何年？」を含める。
2. **人物は受信箱の向こう側に存在する。** 常時立ち絵ではなく、文体、返信速度、添付写真で存在感を作る。
3. **低解像度を演出にする。** 読みにくくするのではなく、欠損、文字化け、再圧縮を重要な場面だけで使う。
4. **選択肢を少なく、結果を近くする。** 各返信は2〜3択とし、次の1通で反応を返す。
5. **構造で反転させる。** 三択、進捗、ENDを物語外のUIにせず、27分岐の人格復元実験そのものにする。
6. **作者の声を優先する。** MVPではLLMによる自由会話を使わず、短く推敲した台詞だけを配信する。
7. **読者を待たせない。** 読者は数秒で進み、相手側だけが数分、3日、18年を経験する。

## 想定ユーザーと利用時間

- 00年代の携帯・ネット文化、短編SF、ビジュアルノベルが好きな人
- 1セッション6〜9分。待ち時間を強制せず、短い画面を連続して読める
- 第1話は1回で完結しつつ、次話の問いを残す
- スマートフォンを取り出さず、G2と任意のR1だけで最後まで進行できる

## 作品の距離感

舞台の空気は2008年の秋葉原、携帯メール、私設BBS、中古端末、ジャンクパーツから得る。ただしタイトルや固有名に「アキバ」を直接使用せず、既存作品の固有設定、人物造形、衣装、台詞回しを模倣しない。

本作はタイムマシンの発明を描かない。中心に置くのは「死者の記録から作られた文章を、何を根拠に本人と見なすのか」というデジタル人格、災害記録、読者参加の倫理である。

## ハッカソン用デモ

60秒で次を見せる。

1. `圏外 / NO SERVICE`と古い携帯風の受信画面を表示する。
2. 2008年の日付を持つ「届いてる？」を開く。
3. `{{currentYear}}年`と返信する。
4. 読者側の数秒に対し、相手側では11分進んだと分かる。
5. 人の消えた通り、顔写真、献花を1-bit添付で見せる。
6. ミナの死亡記録と、17台の回収端末画像を開く。
7. `BRANCHES STORED: 27 / CURRENT READER: 28`で三択自体を物語へ反転させる。

## 非目標

- 自由入力のAIチャット
- 戦闘、探索マップ、スコア、アイテム収集
- 常時マイク、位置情報、カメラ権限
- 他アプリの上に表示するシステム常駐
- 実在キャリア、店舗、掲示板、既存作品の再現
- 通信原理を科学的に説明し切ること
