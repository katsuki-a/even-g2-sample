# コンセプト

## プロダクト定義

**タイトル:** 圏外
**英字表記:** NO SERVICE
**第1話:** 届いてる？

> 17台の壊れた携帯を、眼鏡越しの現実で補完する。見えた少女は、死者か、あなたが足した画素か。

「圏外」は、Even Realities G2の透明な視界内表示を、17台の破損液晶を重ねる光学復元器として扱う短編SFミステリーである。プレイヤーは2008年の日付を持つメールを受信するが、相手のミナは2026年には死者であり、台詞と事故画像は17台の欠損画面へプレイヤーが選んだ視界の白黒を足した共同制作物だったと判明する。

## 体験の核

最先端デバイスと古い携帯画面のミスマッチを、次の一文で説明できることを最優先する。

> この眼鏡は死者のメールを受信したのではなく、欠けた事故記録を現在の視界で埋める実験へ接続してしまった。

G2の制約を隠さず、すべて物語へ変換する。

| G2の特徴 | 体験内での意味 |
| --- | --- |
| 透明な視界内表示 | 現実の輪郭を破損液晶の欠損へ重ねる光学層 |
| 緑色で粗い文字 | 17台の古い1-bit相当画面を共通形式へ変換した表示 |
| 音声出力がない | 着信音さえ失われた静かなメール |
| 上下・決定中心の入力 | ガラケーの方向キーと決定ボタン |
| 200×100のモノクロ画像 | 20,000画素のどこを読者の白黒で補ったか示す証拠 |
| 文字中心の表示 | 短い件名と本文で進む携帯メール |
| G2の実時刻・電池 | 古いUIへ現在が漏れ込む証拠 |

## デザイン原則

1. **最初の30秒で異常を示す。** 最初のメールには2008年の日付と「そっちは何年？」を含める。
2. **人物は職業語彙で識別させる。** 端末の傷、棚番号、在庫、ゼロと不明の区別をミナの声へ一貫して残す。
3. **低解像度を因果にする。** 読みにくくするのではなく、欠損画素を何で埋めたかが事故記録と終端を変える。
4. **選択肢を少なく、結果を近くする。** 各返信は2〜3択とし、次の1通で反応を返す。
5. **構造で反転させる。** 三択、進捗、ENDを物語外のUIにせず、27通りの光学マスクと27個の事故記録そのものにする。
6. **作者の声を優先する。** MVPではLLMによる自由会話を使わず、短く推敲した台詞だけを配信する。
7. **読者を待たせない。** 読者は数秒で進み、相手側だけが数分、3日、18年を経験する。

## 想定ユーザーと利用時間

- 00年代の携帯・ネット文化、短編SF、ビジュアルノベルが好きな人
- 1セッション6〜9分。待ち時間を強制せず、短い画面を連続して読める
- 第1話は1回で完結しつつ、次話の問いを残す
- スマートフォンを取り出さず、G2と任意のR1だけで最後まで進行できる

## 作品の距離感

舞台の空気は2008年の日本の電気街、携帯メール、私設BBS、中古端末、ジャンクパーツから得る。場所は架空都市「東央市」の北電気街とし、現実の事件の日時、場所、犯行、被害者数とは対応させない。

本作はタイムマシンの発明を描かない。中心に置くのは「欠損記録を善意で補ったとき、それを証言と呼べるのか」という災害記録、出典、同意、読者参加の倫理である。

## ハッカソン用デモ

60秒で次を見せる。

1. `圏外 / NO SERVICE`と古い携帯風の受信画面を表示する。
2. 2008年の日付を持つ「届いてる？」を開く。
3. `{{currentYear}}年`と返信する。
4. 読者側の数秒に対し、相手側では11分進んだと分かる。
5. 17台の欠損画面がG2の透明表示で一枚になる1-bit添付を見せる。
6. 階段、非常口、閉眼のどの輪郭を2008年へ重ねるか選ばせる。
7. ミナの死亡記録と、`READER MASKS: 27 / CURRENT LENS: 28`を開く。
8. 三択が返信ではなく、事故記録の欠損画素を決める操作だったと反転させる。

## 非目標

- 自由入力のAIチャット
- 戦闘、探索マップ、スコア、アイテム収集
- 常時マイク、位置情報、カメラ権限
- 他アプリの上に表示するシステム常駐
- 実在キャリア、店舗、掲示板、既存作品の再現
- 通信原理を科学的に説明し切ること
