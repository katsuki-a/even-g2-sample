# Iteration 2026-08-07-01

## 仮説

2008年との素朴な時間通信を、架空の電気街停電事故、死者の人格復元、27分岐を読む28人目というメタ構造へ置き換えれば、短時間で読み進められるまま、ミナの死と偽の差出人を構造的などんでん返しとして成立させられる。ENDを決定入力で閉じなければ、暗転不具合も「次の受信箱が待つ」という終幕へ転換できる。

## 対象

- 種別: story / engine / renderer / polish
- 適応度項目: Story / Gameplay Narrative / SDK適合 / Simulator
- 変更前スコア: implementation 100/100、Story 100/100、旧ストーリー14ノード・添付1枚

## 変更

- ミナを2008年8月17日の架空停電事故で死亡した19歳と確定し、実際のメール相手を17台の端末から作られた人格復元モデル`M-17`へ変更した。
- 東央市・北電気街の信号、看板、端末が一斉停止する事故を設定し、現実の事件の日時、場所、犯行、被害者数と対応させない方針へ改稿した。
- 三択3回の27分岐をモデルの保存分岐、プレイヤーを28人目の読者として物語内へ組み込んだ。
- プレイヤー側は待ち時間なし、相手側は入力ごとに11分、3日、18年が進む非対称な時間へ変更した。
- 1経路を20ノードへ拡張し、本文を短画面へ分割した。全27経路、3終端を維持した。
- 停電した通り、事故翌日の店先、17台の端末の新規1-bit BMPを追加し、既存の人物画像と合わせて全経路4添付とした。
- 添付ローダーを単一画像固定から`AttachmentNode.asset`参照へ変更した。電話プレビューでは次の添付へ移る際に前画像を消す。
- ENDの決定入力は最終ページを再描画して保持し、戻る入力だけが`shutDownPageContainer(1)`を呼ぶようにした。
- Simulator証跡を、END保持後の同一画面と戻る終了の両方を検査するように更新した。

## 画像生成

Built-in ImageGenを使用し、既存`PIC_0047.BMP`をスタイル参照として次の3プロンプトで生成後、200×100の1-bit BMPへ変換した。

1. `2008年の架空の電気街にある中古携帯店内から、信号と看板が一斉に消灯した通りと放置された傘を見る。暴力や人物は直接描かない。既存画像と同じ高コントラスト1-bit漫画ピクセル画、横長2:1、縮小時に判別できる大きな形。`
2. `架空の広域停電事故翌朝、閉じた中古携帯店の前に花、飲料、折り鶴、小さな19歳の女性店員の額を置く。節度ある記録写真として描き、暴力や流血は描かない。高コントラスト1-bit漫画ピクセル画、横長2:1。`
3. `2008年型の壊れた携帯を4×4と下中央1台、正確に17台並べ、各画面の断片が少女の顔を暗示する俯瞰の資料画像。高コントラスト1-bit漫画ピクセル画、文字・ロゴなし、横長2:1。`
